# ElvionWeb Outro

9:16 (1080 x 1920) animated outro for website showcase videos.

## Run
    npm install
    npm run dev

Open the printed URL (usually http://localhost:5173).

- Press R or click the screen to replay.
- Recording view: add ?capture=1 to the URL (add &motion=on if your OS has "reduce motion" enabled).

## Customize
Edit `src/outro/outro.config.js`: text, colors (accent "#00BFFF" cyan, or "#D4AF37" gold), timing, logo size.

## Logo
Your logo is `public/elvionweb-logo.jpg`. To use another file, replace it or change `logoSrc` in the config.
A transparent PNG is best if you change the background color.
